# ACME Pay: frontend

React + TypeScript + Vite single-page app for the salary management system.

Setup, scripts, configuration and architecture are documented in the [root README](../README.md).

```bash
npm install
npm run dev      # http://localhost:5173 (proxies /api to localhost:8000)
npm test         # unit tests (Vitest)
npm run e2e      # end-to-end tests (Playwright; needs the backend running and seeded)
npm run build    # type-check + production build
```
